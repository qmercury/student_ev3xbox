# Robottagram EV3 연결 도우미 (Windows + Mac)

이 VSCode 확장은 학생이 SSH 명령을 직접 입력하지 않고, EV3를 선택한 뒤 교사의 최초 인증만으로 `Ctrl + Shift + B` 배포를 사용할 수 있도록 돕습니다.

## 한 번만 설치하기 (교사 준비)

- VSCode, Python 3, OpenSSH Client가 설치되어 있어야 합니다. Mac은 기본 제공되는 경우가 많고, Windows 10/11에서는 **OpenSSH Client** 기능을 사용합니다.
- EV3는 같은 Wi-Fi에 연결되어 있어야 하며, 교사가 미리 설치한 `xbox_service.py`가 UDP 5005에서 실행되어 **로봇 ID로 자동 검색**될 수 있어야 합니다.
- 로봇에 접속할 `robot` 계정 및 비밀번호를 알고 있어야 합니다. 변경하지 않은 ev3dev 기본 설정의 경우 비밀번호는 `maker`이지만, 변경했다면 변경된 값을 사용합니다.

### 확장 설치 파일(.vsix) 만들기

이 폴더에서 한 번 실행합니다. 패키징 PC는 최초 설치 시 인터넷에 연결되어 있어야 합니다.

```bash
cd vscode-extension
npm install
npm run check
npm run package
```

생성된 `robottagram-ev3-connect-0.1.0.vsix` 파일을 Windows/Mac에 복사한 뒤, VSCode의 **확장 → … → VSIX에서 설치**로 설치하세요. 학생 컴퓨터에는 npm을 설치할 필요가 없습니다. VSIX에는 실행에 필요한 JavaScript 의존성이 함께 포함됩니다.

## 학생 사용 방법

1. VSCode에서 `student_ev3xbox` 폴더를 엽니다.
2. `Ctrl + Shift + P` (Mac: `Cmd + Shift + P`) → **EV3: 최초 연결 도우미 열기** 선택
3. **EV3 자동 검색** → 내 EV3 선택 → **선택한 EV3 최초 연결** 클릭
4. 첫 인증 시 교사가 EV3의 SSH 서버 키 지문을 확인하고, EV3 비밀번호를 입력합니다.
5. **연결 준비 완료**가 표시되면 `main.py` 작성 후 `Ctrl + Shift + B`로 자동 업로드 및 실행합니다.

이미 키 등록이 끝난 노트북은 비밀번호 없이 기존 SSH 개인키를 재사용합니다.

## 보안 및 주의 사항

- SSH 개인키는 노트북의 `~/.ssh/ev3_classroom_ed25519`에 생성됩니다. GitHub와 학생 프로젝트 폴더에는 저장되지 않습니다.
- 교사가 입력한 비밀번호는 연결에만 사용하고 파일, 설정, 로그에 기록하지 않습니다.
- 처음 나타나는 SSH 서버 키 지문은 교사가 로봇을 확인한 뒤 승인하세요. 로봇 ID의 서버 키가 바뀌면 **자동 연결을 차단**합니다. 재설치된 로봇의 신뢰 등록을 갱신해야 할 때는 별도 관리 절차가 필요합니다.
- **자동 검색이 안 될 때:** 노트북/EV3가 같은 Wi-Fi인지, 공유기의 AP 격리 기능이 꺼져 있는지, EV3의 Xbox 상주 서비스(UDP 5005)가 실행 중인지 확인하세요.
- 이 연결 도우미는 학생 프로그램을 배포하고 Xbox 조종 서비스를 설치하는 도구가 아닙니다. **교사의 EV3 초기 설치 작업은 별개**입니다.
- `Ctrl + Shift + B`는 기존 `tools/ev3_deploy.py`와 SSH/SCP를 그대로 사용합니다. 본 확장은 최초 연결과 설정 파일 생성을 도와줍니다.
- Wi-Fi가 바뀌면 **EV3 자동 검색 → 같은 로봇 선택 → 최초 연결**을 다시 실행하면 새 IP로 설정이 갱신됩니다(로봇 서버 키가 같아야 함).
