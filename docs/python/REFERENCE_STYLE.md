# 학생용 레퍼런스 작성 원칙

이 문서는 교사용 개발 메모가 아니라 **학생이 코드를 작성하면서 바로 찾아보는
API 레퍼런스**입니다.

각 기능 문서는 다음 순서를 사용합니다.

```text
1. import
2. 객체 만들기
3. 가장 많이 쓰는 기능
4. 메서드/속성 이름
5. 인자 설명
6. 짧은 예제
7. 주의할 점
8. 공식 문서
```

## 수업에서 검증하는 것과 만들지 않는 것

이 저장소가 제공하는 것은:

```text
EV3 Python 실행환경
python-ev3dev2 사용 방법
XboxController API
VSCode 배포 환경
학생용 레퍼런스
```

입니다.

학생별 로봇의:

```text
주행 알고리즘
슈터 알고리즘
속도 단계
버튼 배치
센서 전략
경기 전략
```

은 레퍼런스에 정답 코드로 고정하지 않습니다. 학생이 API를 조합하고 실제
로봇에서 디버깅하면서 작성합니다.

## 예제 원칙

예제는 API의 사용법을 보여주기 위한 최소 코드만 제공합니다.

예:

```python
motor.on(
    SpeedPercent(50)
)
```

완성된 경기 프로그램은 레퍼런스 예제로 제공하지 않습니다.

## async 원칙

`async`, `await`, `asyncio`는 EV3 전용 기능이 아니라 Python 3의
표준 기능입니다.

학생이 로봇 기능을 나눌 때 사용할 수 있도록 문서화하지만 특정 task 구성이나
알고리즘을 강제하지 않습니다.
